Portable reproducibility package for the cage-aware mouse age prediction model generated by `xgb_age_cage_gpu_full.py`.

This directory is intended to be uploaded instead of the pickle file. It contains plain-text split tables, prediction outputs, and an XGBoost-native model file that is much more portable than Python pickle serialization.

## Software environment

The reference software environment for this analysis is provided separately as:

- `xgb_gpu0.yml`

This YAML file should be uploaded together with this directory if you want users to recreate the original conda environment as closely as possible.

- `numpy = 2.3.5`

### What is actually required for this directory

To use the files in this split directory, the essential packages are:

- `xgboost`
  - required to load `final_xgb_model.json` and reproduce predictions
- `pandas`
  - required to read the CSV and CSV.GZ tables
- `numpy`
  - required for array handling and metric recomputation

`scikit-learn` is not strictly required just to load the model and predict, but it is useful if users want to recompute `MAE`, `RMSE`, or `R2`.

### Why the split directory is preferred over the pickle

The original pickle is more sensitive to package-version compatibility, especially for:

- `pandas`
- `xgboost`
- `scikit-learn`

For that reason, this split directory plus `xgb_gpu0.yml` is the recommended public reproducibility package.

## What this package contains

This package corresponds to the pooled `ALL` analysis with:

- target: `age.approx.wks`
- leakage control group: `Cage`
- holdout strategy: cage-aware balanced group holdout
- cross-validation: `StratifiedGroupKFold`
- final model type: `XGBRegressor`

## Main results

- Holdout test set:
  - `n_train_samples = 2426`
  - `n_test_samples = 571`
  - `n_train_groups = 96`
  - `n_test_groups = 24`
  - `n_shared_groups = 0`
- Holdout performance:
  - `MAE = 10.6719`
  - `RMSE = 15.2790`

  - mean `RMSE = 17.1927`
  - mean `R2 = 0.8234`

## File overview

### Core files

- `final_xgb_model.json`
  - XGBoost-native saved final model.
- `used_xgb_params.json`
  - Final parameter set used for outer CV and final fitting.
- `holdout_split_report.json`
  - Summary of the cage-aware holdout split, including test cages and stratum counts.
- `outer_cv_summary.json`
  - Mean and SD of outer CV performance.
- `holdout_test_metrics.json`
  - Final held-out test performance.

### Holdout train/test data

- `holdout_train_clr.csv.gz`
- `holdout_test_clr.csv.gz`
  - CLR-transformed abundance matrices.
  - Rows are samples and columns are model features.
- `holdout_train_meta.csv`
- `holdout_test_meta.csv`
  - Metadata for the matching train/test samples.
- `holdout_train_samples.txt`
- `holdout_test_samples.txt`
  - Plain sample ID lists for the holdout split.

### Prediction outputs

- `holdout_test_predictions.csv`
  - Sample-level predictions for the held-out test set.
- `outer_cv_metrics.csv`
  - Per-fold outer CV metrics.
- `outer_cv_predictions.csv`
  - Validation predictions from outer CV.

### CV split definitions

- `cv_splits.json`
  - Machine-readable record of all outer CV folds.
- `cv_fold_01/` to `cv_fold_10/`
  - For each fold:
    - `train_samples.txt`
    - `val_samples.txt`
    - `train_meta.csv`
    - `val_meta.csv`

## Recommended use

If you want users to reproduce the reported results, this directory is the recommended artifact to upload.

It is preferable to the pickle because:

- the pickle depends on compatible Python package versions
- the XGBoost JSON model is safer and more portable
- the split tables make the exact train/test and CV partitions explicit

## Minimal reproduction workflow

### 1. Load the final model

```python
from xgboost import XGBRegressor

model = XGBRegressor()
model.load_model("final_xgb_model.json")
```

### 2. Load the held-out test matrix

```python
import pandas as pd

X_test = pd.read_csv("holdout_test_clr.csv.gz", index_col=0)
meta_test = pd.read_csv("holdout_test_meta.csv", index_col=0)
pred_ref = pd.read_csv("holdout_test_predictions.csv")
```

### 3. Reproduce held-out predictions

```python
y_pred = model.predict(X_test.values)
```

The resulting predictions should match the `y_pred` column in `holdout_test_predictions.csv` up to normal floating-point tolerance.

## Notes

- The original workflow used GPU-enabled XGBoost during training, but prediction from `final_xgb_model.json` can also be run on CPU.
- This package does not include the full original unsplit input tables; instead, it includes the exact split matrices needed to reproduce the reported CV and holdout evaluation.
- If full rerun-from-raw-input reproducibility is desired, upload this directory together with the original metadata table, original CLR abundance table, and the training script.
